Kiro には、一般的な開発ワークフローに対応した組み込みエージェントが搭載されています。これらはカスタムエージェントと同じエージェントフレームワークを使用していますが、Kiro によってあらかじめ設定され、メンテナンスされています。セッション中にこれらを切り替えたり、専用の UI コントロールやスラッシュコマンドを使って呼び出したりすることができます。

| エージェント | IDE | CLI | 目的 |
| --- | --- | --- | --- |
| **デフォルト** | ✓ | ✓ | 汎用コーディングアシスタント |
| **仕様** | ✓ | ✓ | 構造化された機能開発（要件、設計、タスク） |
| **クイック・スペック** | ✓ | ✓ | 高速仕様書作成ワークフロー - 承認ゲートなしで全フェーズを自動生成 |
| **バグ修正** | ✓ | ✓ | 体系化されたバグ調査と解決 |
| **計画** | ✓ | ✓ | 実行前の読み取り専用計画 |
| **ガイド** | — | ✓ | ドキュメントに基づいたCLIヘルプ（ターミナルUI） |
| **ヘルプ** | — | ✓ | ドキュメントに基づいた CLI ヘルプ（従来のインターフェース） |

## デフォルトのエージェント

デフォルトのエージェントは、すべてのセッションの開始時に起動する汎用アシスタントです。このエージェントは、すべての組み込みツール、MCPサーバー、およびワークスペースのコンテキストにアクセスできます。コードの記述、デバッグ、リファクタリング、質問への回答など、ほとんどの開発タスクはここで行われます。

明示的に起動する必要はなく、すべてのセッションの起点となります。

## 仕様エージェント

Spec、Quick Spec、およびBug Fixエージェントは、`.kiro/specs/`に保存される正式な要件、設計、およびタスク文書を生成します。これらは、各フェーズの間に承認ゲートを設けた構造化されたフェーズを通じて、ユーザーを導きます。

新しいセッションを開始する際、**「Let's build」**画面の「Start with a workflow」の下に、ワークフローのオプションが表示されます：

| ワークフロー | 生成されるもの |
| --- | --- |
| **仕様** | 要件 → 設計 → タスク（各フェーズ間に承認ゲートあり） |
| **簡易仕様** | 3つのフェーズすべてが承認ゲートなしで自動生成される - 実装への最短ルート |
| **バグ修正** | 根本原因分析 → 設計修正 → 実装タスク |

ワークフローを選択して、そのエージェントとのセッションを開始します。また、チャット入力エリアの「**仕様書でビルド」**をクリックすることで、セッション中に仕様書を呼び出すこともできます。

構造化された開発ワークフローに関する完全なガイドについては、「[仕様書」を](https://kiro.dev/docs/specs/)参照してください。

## プランエージェント

「Plan」モードは、実行前に検討を行うのに役立ちます。このモードは**読み取り専用で**動作し、コードベースの調査、要件の収集、実装計画の作成を、変更を加えることなく行えます。承認すると、デフォルトのエージェントに引き継がれ、実行されます。

新しいセッションを開始する際は、ワークフローセレクターから**「Plan」**を選択するか、セッション中にチャット入力バーのエージェントピッカーを使用して切り替えてください（エージェント名（例：「Default」）をクリックし、「Plan」を選択します）。

### プランモードがアクセスできるもの

| 操作 | 利用可能 |
| --- | --- |
| ファイルの読み取り、コードインテリジェンス、検索 | ✓ |
| Web 検索 | ✓ |
| ファイルへの書き込み、コマンドの実行、MCPツール | — |

プラン モードのワークフローおよびベスト プラクティスの詳細については、「[プラン モード」](https://kiro.dev/docs/specs/plan/)を参照してください。

## ガイドエージェント（CLIのみ）

Guideエージェントは、Kiroに関するドキュメントに基づいた回答を提供します。デフォルトのエージェントが持つ一般的な知識とは異なり、Guideエージェントは、インストールされているバージョンに一致する、インデックス化されたドキュメントを検索します。

bash

```bash
> /guide
```

`Shift+Tab` を押すと、前のエージェントに戻ります。

### 質問できる内容

- **コマンド** - スラッシュコマンド、CLI コマンド、それらのオプションおよび動作
- **設定** - 利用可能な設定オプション
- **機能** - MCP、フック、ステアリング、カスタムエージェント、サブエージェント、コードインテリジェンス
- **ファイルの作成** - `.kiro/` 内でエージェント設定、プロンプト、ステアリングファイルを生成

Guideエージェントは、コンパイル時に埋め込まれたインデックス化されたドキュメントに対して、ハイブリッド検索（セマンティック検索＋BM25）を行う**introspect**ツールを使用しています。

## ヘルプエージェント（CLIのみ）

ヘルプエージェントは、Guideエージェントと同様にドキュメントに基づいた支援を提供しますが、クラシック（非TUI）インターフェースで動作します。`/help` または `/help <question>` で起動します。

## エージェントの切り替え

新しいセッションを開くと、**「Let's build」**画面で以下のワークフローオプションが表示されます：

- **Spec** - 構造化された機能開発
- **Plan** - 計画専用モード（読み取り専用、変更不可）
- **Bug Fix** - 構造化されたバグ調査
- **Quick Spec** - 承認プロセスを省略した迅速な仕様策定ワークフロー

ワークフローを選択すると、そのセッションのアクティブなエージェントが自動的に切り替わります。また、チャットペインの下部バーにあるエージェント名（例：「Default」）をクリックしてエージェントピッカーを開くことで、セッションの途中でエージェントを切り替えることもできます。

## 独自のエージェントの作成

組み込みエージェントは、Kiroが特殊なワークフロー向けにエージェント設定をどのように活用しているかを示しています。ユーザー自身も、特定のワークフローに合わせてカスタマイズされたツール、権限、プロンプト、モデルを備えた、同様の機能を持つ独自のエージェントを作成できます。

開始するには、「[カスタムエージェントの作成」](https://kiro.dev/docs/custom-agents/creating/)をご覧ください。
