「ツール検索」機能では、リクエストごとにすべてのツール定義を送信するのではなく、必要に応じてMCPツールを読み込みます。これにより、多数のMCPサーバーが設定されている場合でもコンテキストウィンドウが整理された状態を保ち、エージェントが適切なツールを自動的に検出できるようになります。

| 機能 | IDE | CLI | Web | モバイル |
| --- | --- | --- | --- | --- |
| ツールの検索 | — | ✓ | — | — |

## ツール検索を有効にするタイミング

以下の場合はツール検索を有効にしてください：

- 5台以上のMCPサーバーが構成されている場合
- 長時間の会話中にコンテキストウィンドウのオーバーフローエラーが発生する場合
- `/tools`コマンドの実行結果で、MCPツールのトークン消費総数が50,000を超える場合

使用するMCPツールがごく少数である場合は、ツール検索によるオーバーヘッドに見合うだけの価値がない可能性があります。

## ツール検索の有効化

Tool Searchはデフォルトで無効になっています。設定から有効にしてください：

bash

```bash
kiro-cli settings toolSearch.enabled true
```

有効にすると、MCPツールの仕様が「先送り」の恩恵を受けるのに十分な規模になった時点で、ツール検索が自動的に作動します。デフォルトの閾値（コンテキストウィンドウの5％または50,000トークン）で、ほとんどのケースをカバーできます。MCPツールが存在する場合に常に作動させるには、閾値を`0`に設定してください：

bash

```bash
kiro-cli settings toolSearch.minPct 0
kiro-cli settings toolSearch.minTokens 0
```

### 設定

以下の設定でツール検索の動作を構成します:

| 設定 | デフォルト | 説明 |
| --- | --- | --- |
| `toolSearch.enabled` | `false` | ツール検索のマスター切り替え |
| `toolSearch.minPct` | `5` | MCPツールの仕様がコンテキストウィンドウのこの％を超えた場合に有効にする |
| `toolSearch.minTokens` | `50000` | MCPのツール仕様がこのトークン数を上回ったときに有効化 |

両方のしきい値が設定されている場合、いずれか一方を超えるとツール検索が有効になります（OR論理）。両方のしきい値が`0`に設定されている場合、MCPツールの数に関係なく、ツール検索は常に有効になります。

## ツール検索が有効かどうかを確認する

ツール検索が有効な場合：

- `/tools`コマンドを実行すると、無効な場合と比較してMCPツールのトークン数が減少していることが確認できます
- オンデマンドでツールを検出する際、エージェントのツール使用状況に「`tool_search`」の呼び出しが表示されます

## 仕組み

1. **インデックス作成**：MCPサーバーが接続すると、キーワード検索用にすべてのツール仕様がインデックス化されます。各ツールの名前、サーバー名、説明、およびパラメータの説明がトークン化されます。
2. **ツールリストの遅延読み込み**：モデルは完全な JSON スキーマではなく、`server_name::tool_name: description` エントリのコンパクトなリストを受け取ります。説明は 1KB に切り詰められます。
3. **オンデマンド読み込み**：モデルがツールを必要とする際、正確な`tool_id`（例：`builder-mcp::InternalSearch`）またはキーワード`query`（例：`"search documents"`）のいずれかを指定して、`tool_search`を呼び出します。
4. **有効化**：一致したツールが読み込まれ、その後のリクエストにはそれらの完全なスキーマが含まれます。

## 組み込みツール「tool_search」

**ツール名**：`tool_search`

オンデマンドで MCP ツールを検索して読み込みます。ユーザーの許可を求めるプロンプトが表示されず、自動的に許可されます（読み取り専用）。

### パラメータ

`tool_search` ツールは、以下のパラメータを受け付けます：

| パラメータ | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| `tool_id` | 文字列 | `tool_id` または `query` のいずれか | `server_name::tool_name`形式の正確なツール識別子 |
| `query` | 文字列 | `tool_id` または `query` のいずれか | 一致するツールを検索するためのキーワード |
| `max_results` | 整数 | なし | 返す結果の最大数（デフォルト：5） |

`tool_id` または `query` のいずれか一つを指定してください。両方を指定しないでください。一致したツールは即座に有効化され、呼び出し可能になります。

### キーワード一致検索

キーワード検索では、BM25 関連度スコアリングが使用されます。ツール名は、大文字小文字の境界で分割され（例：`ReadFile` → `read file`、`read_file` → `read file`）、マッチング精度が向上します。マッチングの閾値を超える結果のみが返されます。

デフォルトの閾値は `1.5` ですが、環境変数 `KIRO_CLI_TOOL_SEARCH_MATCHING_THRESHOLD` を通じて設定可能です。
