Model Context Protocol（MCP）は、追加のツールやコンテキストを提供する専用サーバーに接続することで、Kiroの機能を拡張します。このガイドでは、あらゆるプラットフォームにおいて、KiroとMCPサーバーをセットアップ、設定、および使用する方法について説明します。

| --- | --- | --- | --- | --- |
| ローカル (stdio)MCP サーバー | ✓ | ✓ | ✓ | — |
| リモート (HTTP/SSE) MCP サーバー | ✓ | ✓ | ✓ | — |
| MCP設定ファイル（JSON） | ✓ | ✓ | ✓ | — |
| サーバーが提供するプロンプトとリソース | ✓ | ✓ | ✓ | — |

## MCPとは？

MCPは、Kiroが外部サーバーと通信して、専用のツール、プロンプト、リソースにアクセスできるようにするプロトコルです。例えば、AWSドキュメントのMCPサーバーは、Kiro内で直接AWSドキュメントを検索、閲覧し、推奨事項を取得するためのツールを提供します。

MCP を使用すると、以下のことが可能になります：

- 専門的なナレッジベースやドキュメントへのアクセス
- 外部サービスやAPIとの連携
- ドメイン固有のツールでKiroの機能を拡張する
- チャット内の「`#`」メンションシステムを通じて、サーバーが提供するプロンプトテンプレートやリソーステンプレートを使用する
- ツールの実行中に追加の入力が必要な場合、サーバーからの情報提供リクエストに応答する
- 特定のワークフローに合わせたカスタムツールを作成する

## MCPの設定

### 前提条件

MCP を使用する前に、以下の条件が満たされていることを確認してください:

1. Kiroの最新版がインストールされていること
2. 使用するMCPサーバーごとの具体的な前提条件（各サーバーのドキュメントに記載されています）

### MCPサーバーの追加

1

#### MCPの設定を開く

コマンドパレット（Macの場合は`Cmd + Shift + P`、Windows/Linuxの場合は`Ctrl + Shift + P`）を開き、「**Kiro: ワークスペースの MCP 設定を開く (JSON)**」または「**Kiro: ユーザーの MCP 設定を開く (JSON)**」を検索します。

または、Kiro パネルを開き、「**MCP 設定を開く」**アイコンを選択します。

2

#### サーバー設定を追加する

json

```json
{
  "mcpServers": {
    "fetch": {
      "command": "uvx",
      "args": ["mcp-server-fetch"],
      "disabled": false
    }
  }
}
```

3

#### 保存して確認する

設定ファイル（`Cmd+S`）を保存します。サーバーは自動的に再接続されます。Kiroパネルの「MCPサーバー」タブを確認し、サーバーが接続されていることを確認してください。

### インストールリンクからのインストール

一部のサーバーディレクトリやウェブサイトでは、`kiro://`というURLスキーマを使用したワンクリックインストールリンクが提供されています。これらのリンクを開いても、設定はすぐには変更されません。Kiroは、設定ファイルに何かが書き込まれる前に確認ダイアログを表示します。このダイアログには、実行されるコマンドとその引数、および環境変数やヘッダーの名前が一覧表示されますが、それらの値は非表示のままです。 詳細を確認し、「確認」をクリックしてサーバーを追加するか、「キャンセル」をクリックして設定を変更せずに終了してください。

### エージェントの設定

エージェントの設定ファイル内で直接MCPサーバーを定義することも可能です。「`mcpServers`」フィールドは、エージェントがアクセスできるMCPサーバーを指定します：

json

```json
{
  "name": "myagent",
  "description": "My special agent",
  "mcpServers": {
    "fetch": {
      "command": "fetch3.1",
      "args": []
    }
  },
  "includeMcpJson": false
}
```

`includeMcpJson`フィールドは、ワークスペースおよびユーザーレベルの設定ファイルで定義されたMCPサーバーを含めるかどうかを決定します。`true`に設定すると、エージェントは、エージェント自身の`mcpServers`フィールドで定義されたサーバーに加え、ユーザーおよびワークスペースレベルの設定で定義されたすべてのMCPサーバーにアクセスできるようになります。

## トラブルシューティング

### MCPログの確認

1. Kiroパネルを開く
2. [出力] タブを選択します
3. ドロップダウンから「Kiro - MCP ログ」を選択します

### よくある問題と解決策

| 問題 | 解決策 |
| --- | --- |
| 接続エラー | 前提条件が正しくインストールされているか確認してください |
| 権限エラー | トークンとAPIキーが有効であることを確認してください |
| ツールが応答しない | MCPのログを確認し、具体的なエラーメッセージを確認してください |
| 設定が読み込まれない | JSONの構文を確認し、設定ファイルを保存してください |

### ツールの検証エラー

「検証エラーのため、以下のツールが除外されました」というメッセージが表示された場合、そのツールは以下の要件のいずれかを満たしていません：

- ツール名が64文字を超えている（サーバープレフィックスを含む）
- ツール名に無効な文字が含まれている（`^[a-zA-Z][a-zA-Z0-9_]*$` に準拠している必要があります）
- ツールの説明が空である

ツールの仕様を修正するには、MCPサーバーの管理者にお問い合わせください。

### 説明文が長い場合の警告

「以下のツールは説明文が長いため、エージェントのパフォーマンスに影響を与える可能性があります」というメッセージが表示された場合、ツールの説明文が 10,000 文字を超えています。ツール自体は動作しますが、応答が遅くなる可能性があります。サーバー管理者に説明文を短縮するよう依頼することを検討してください。
