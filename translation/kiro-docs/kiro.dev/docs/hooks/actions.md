エージェントフックは、「エージェントプロンプト」と「シェルコマンド」の両方のアクションに対応しています。フックを[トリガー](https://kiro.dev/docs/hooks/types/)する特定のイベントを選択したら、そのフックがトリガーされた際に実行するアクションを決定できます。

## エージェントプロンプトアクション

このアクションを使用すると、フックがトリガーされるたびにエージェントに送信されるプロンプトを定義できます。エージェントは、チャットパネルで表示されるプロンプトと同様に、このプロンプトに応答し、それに基づいて行動します。

「[プロンプト送信](https://kiro.dev/docs/hooks/types/#prompt-submit)」トリガーの場合、フックで指定されたプロンプトはユーザープロンプトに*追加され*、結合されたプロンプトがエージェントに送信されます。

## シェルコマンドアクション

このアクションを使用すると、フックがトリガーされるたびに実行されるシェルコマンドを定義できます。

コマンドが成功を示す終了コード「0」を返した場合、コマンドの *stdout* 出力がエージェントのコンテキストに追加されます。

コマンドがそれ以外の終了コードを返した場合、コマンドの *stderr* 出力がエージェントに送信され、フックがエラーを返したことがエージェントに通知されます。さらに、「**ツール使用前**」フックの場合はツールの呼び出しがブロックされ、「**プロンプト送信**」フックの場合はユーザーによるプロンプトの送信がブロックされます。

実行タイムアウトを指定できます。デフォルトのタイムアウトは 60 秒です。タイムアウトを無効にするには、0 に設定してください。

## アクションタイプの選択

トリガーイベントに応じて、自然言語を使用してエージェントにコンテキストに基づいた何らかのアクションを実行するよう指示したい場合は、「**Agent Prompt**」アクションを使用する必要があります。

特定のコマンドを実行したり、エージェントの現在のコンテキストに依存しない決定論的な一連のアクションを実行したりする場合は、「**Shell Command**」アクションを使用してください。
