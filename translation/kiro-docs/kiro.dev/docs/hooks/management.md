効果的なフックの管理により、プロジェクトが拡大しても、自動化ワークフローを整理された状態に保ち、保守性を維持し、効率性を高めることができます。

## フックの管理

Kiroパネルの「Agent Hooks」セクションから、すべてのフックにアクセスできます。

### フックの作成

「Agent Hooks」セクションの**「+**」ボタンをクリックします。以下の2つのオプションが表示されます。

- **ステアリングファイルを手動で作成** - ``/<filename>`` スラッシュコマンドとして呼び出される Markdown 形式のステアリングファイルを作成します
- **Kiroにフックの作成を依頼する** - チャットにプロンプトが事前入力され、そこで自然言語でフックの内容を説明し、エージェントと対話して設定を行います

**「Kiroにフックの作成を依頼する**」を選択すると、チャット入力欄には、Kiroにフックの機能概要を尋ねるプロンプトが事前に入力されています。そこから、希望する内容を説明すると、Kiroが会話を通じてフックの設定を生成します。

### フックの有効化／無効化

フックを削除せずに有効化／無効化するには：

- **クイック切り替え**：「Agent Hooks」パネル内の任意のフックの横にある「`eye icon`」をクリックします
- **フック画面から**：フックを選択し、右上隅にある「`Hook Enabled`」スイッチを使用します

### 既存のフックの編集

フックはワークフローに合わせて変化します。「Agent Hooks」パネルでフックを選択し、設定を変更することで、いつでも更新できます。変更は即座に反映されます。

### フックの削除

「Agent Hooks」パネルでフックを選択し、画面下部にある「`Delete Hook`」をクリックしてから、「`delete`」をクリックします。この操作は元に戻せません。

### レガシー手動フックの実行

IDE 0.x で作成された手動フックは、引き続き「**レガシー」**というラベル付きで表示されます。有効になっているレガシー手動フックは、以下の方法で実行できます。

- **クイック実行**：「Agent Hooks」パネル内のフック名の横にある「`play button (▷)`」をクリックします
- **フックビューから**：フックを選択し、右上隅にある「`Start Hook`」をクリックします

新しいオンデマンドワークフローを作成するには、代わりに[手動で組み込まれたステアリングファイル](https://kiro.dev/docs/steering/#manual-inclusion)を作成してください。
